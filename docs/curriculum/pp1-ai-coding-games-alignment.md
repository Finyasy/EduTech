# PP1 Maths Alignment To AI, Coding, And Games

## Principle

Maths remains the source of truth. AI, coding, and games are support layers that make a CBC/CBE maths competency easier to practice, observe, and review.

## PP1 Term 2 Alignment Matrix

| Maths competency | Classroom activity | AI bridge | Coding bridge | Game mechanic | Evidence |
| --- | --- | --- | --- | --- | --- |
| Count concrete object sets from 5 to 9 | Make sets using cups, tins, bottle tops, seeds, or sticks | Helper labels sets by quantity and learners correct wrong labels | First, next, last and repeat-count routines | Choose the numeral that matches a set | Learner counts each object once and matches the set to the numeral |
| Order numbers 1-9 and identify missing numbers | Arrange number cut-outs and complete strips | Helper predicts the missing number | Debug an out-of-order sequence | Complete the number path | Learner orders numbers and names before/after |
| Model, trace, join, write, and type early numerals | Form numerals with plasticine, chalk, sand trays, or tracing sheets | Helper compares numeral shapes | Type a numeral and match it to a physical set | Match numeral shape to quantity | Learner makes a recognizable numeral and links it to a count |
| Compare long and short sides or objects | Sort classroom objects or pictures | Helper sorts by length and learner explains mistakes | If long, place here; if short, place there | Choose long/short group | Learner identifies longer/shorter and explains one comparison |
| Compare heavy and light safe objects | Lift, sort, and match objects | Train helper with heavy/light examples | Conditional sorting rule | Sort or choose heavy/light item | Learner sorts one heavy and one light object correctly |
| Fill, empty, compare, and count capacity | Use small tins or cups to fill a bigger container | Helper predicts which container holds more | Repeat-fill loop | Choose how many small containers fill a big one | Learner counts fills and uses comparison words |
| Sequence daily routine events | Order morning, school, home, and evening cards | Helper predicts the next card | First, next, then, last | Put routine cards in order | Learner orders events and uses one time word correctly |

## First Vertical Slice

Start with `PP1 Term 2 Week 1: Counting 5-9`.

- Lesson focus: learners count household object sets and match each set to a numeral.
- Game: `PP1 Count The Set`.
- Teacher evidence: observation note plus game attempt showing whether the learner counted each object once.
- Next build: number sequencing after the counting slice is reviewed with real teacher feedback.

## Reusable Game Templates

| Template | Mechanic | Best for | Evidence |
| --- | --- | --- | --- |
| Count The Set | Choose the numeral that matches a set of objects | PP1 counting and number recognition | Correct numeral choice and attempt pattern |
| Complete The Sequence | Choose the missing number or routine card | Number sequencing and daily routine ordering | Missing-number accuracy and before/after vocabulary |
| Sort By Rule | Classify items into the correct group | Classification, long/short, heavy/light, same/different | Rule use, correction behavior, explanation |
| Fill And Count | Count repeated fills into a big container | Capacity, one-to-one counting, repeat-loop language | Fill count, comparison words, support level |
