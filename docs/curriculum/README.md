# Curriculum Review Pack

This folder contains the Kenya CBC/CBE maths curriculum review artifacts for PP1 through Grade 3 planning.

## Start Here

1. `kenya-pp1-to-grade3-maths-implementation.md`
   - Source alignment
   - PP1 full-year skeleton
   - PP1-to-PP2 progression matrix
   - PP1-to-Grade 3 competency ladder
   - Reviewer checklist

2. `pp1-term-2-maths-map.md`
   - Cleaned PP1 Term 2 weekly map
   - Detailed lesson map
   - Week 13 Time/Daily Routine correction
   - Local resource bank
   - Digital support rules

3. `pp1-maths-assessment-bank.md`
   - PP1 mastery levels
   - Rubric bank by sub-strand
   - Learner evidence checklist
   - Weekly review tasks

4. `pp1-ai-coding-games-alignment.md`
   - PP1 Term 2 maths-to-product alignment
   - AI and coding bridges
   - Maths game templates
   - First vertical slice

5. `math-roadmap-thread-briefs.md`
   - Shareable implementation briefs for student frontend, teacher frontend, UI/UX, and backend threads
   - Cross-thread rules and suggested thread prompts

## Review Order

Review PP1 Term 2 first, then the assessment bank, then the AI/coding/game alignment, then the thread briefs, then the PP1-to-Grade 3 progression. Term 1 and Term 3 should be added later using the same fields and lesson pattern.
