# PP1 Term 2 Mathematical Activities Curriculum Map

## Source And Correction Notes

This map normalizes the supplied PP1 Term 2 scheme into a review-ready CBC/CBE structure. It keeps the original sequence but improves consistency, observable evidence, and Week 13 alignment.

Major correction: Week 13 is treated as Time and Daily Routine. The supplied scheme had container/capacity outcomes under the Time strand, so those outcomes are replaced with routine sequencing.

## Common Lesson Fields

Each lesson should be stored or reviewed with these fields:

| Field | Use |
| --- | --- |
| Week | Term week number |
| Lesson | Lesson number within the week |
| Strand | Classification, Numbers, or Measurement |
| Sub-strand | Focus concept such as counting, sequencing, number writing, long/short, mass, capacity, or time |
| Specific learning outcome | What the learner should do by the end of the lesson |
| Key inquiry question | Question that drives observation and discussion |
| Learning experience | Concrete activity learners perform |
| Local resources | Materials available at home or school |
| Assessment method | Observation, oral questions, worksheet, portfolio, peer task, performance task |
| Mastery evidence | Observable proof of learning |

## Term 2 Weekly Map

| Week | Focus | Lesson sequence | Weekly review task |
| --- | --- | --- | --- |
| 1 | Counting concrete objects 5-9 | L1 count and order 5 household objects. L2 count and color 6 jugs. L3 count and trace 7 plates. L4 recognize and color 8 mugs. L5 count and order 9 cups/tins. | Learner creates sets of 5, 6, 7, 8, and 9 objects and matches each set to the spoken number. |
| 2 | Number sequencing introduction | L1 state number sequence from chart. L2 trace numbers in sequence. L3 order numbers 1-3. L4 arrange numbers 1-5. L5 arrange numbers 1-8. | Learner arranges number cut-outs in order and names the number that comes next. |
| 3 | Missing numbers and ordering | L1 identify missing number in a sequence. L2 compare sequences in pairs. L3 arrange numbers and state what follows. L4 order numbers 1-4. L5 join numbers 1-9. | Learner completes a simple missing-number strip using cut-outs. |
| 4 | Number writing 1-5 | L1 identify and model number 1. L2 discuss and trace number 2. L3 join number 3. L4 color/write number 4. L5 trace number 5. | Learner models or traces numerals 1-5 and matches them to small object sets. |
| 5 | Number writing consolidation and digital support | L1 join number parts. L2 join more number parts. L3 write number of family members. L4 write numbers using a digital device. L5 type numbers using a phone or tablet. | Learner writes or types a number and explains what the number represents. |
| 6 | Long sides of objects | L1 discuss sides of boxes. L2 identify and trace longer side. L3 recognize longer side of chair. L4 join longer side of table. L5 match longer sides in pairs. | Learner identifies the longer side on at least two classroom objects. |
| 7 | Short sides of objects | L1 identify and trace short side. L2 join short side of objects. L3 pair short sides. L4 sort and group short sides. L5 compare short sides of concrete objects. | Learner sorts objects or pictures into long and short groups. |
| 8 | Heavy objects | L1 identify and lift heavy classroom objects safely. L2 name home items and compare heavy/light. L3 take turns lifting objects. L4 pair heavy objects. L5 mention heavy objects and compare with light objects. | Learner sorts safe objects into heavy and light groups and explains one choice. |
| 9 | Mid-term break | No new content. | Optional home practice: count objects, compare heavy/light, and identify long/short objects. |
| 10 | Light objects and heavy/light comparison | L1 identify light home objects. L2 sort light objects. L3 match light objects. L4 differentiate heavy and light. L5 watch/observe lifting demo and play a comparison game. | Learner selects a heavy object and a light object and uses the correct comparison words. |
| 11 | Capacity: small and big containers | L1 pair small and big containers. L2 identify small containers and use them to measure. L3 sort small and big containers. L4 fill and empty a big container. L5 count small containers used to fill a big container. | Learner uses a small cup or tin to find how many fills make a bigger container. |
| 12 | Capacity comparison | L1 identify different container sizes. L2 observe, fill, and empty big containers. L3 compare same containers. L4 identify which container holds more. L5 name big/small containers and observe filling/emptying. | Learner orders containers from small to big or less to more capacity. |
| 13 | Time and daily routine | L1 name morning activities. L2 sequence before-school routine. L3 describe activities at school. L4 sequence going-home routine. L5 compare today, yesterday, and tomorrow using familiar events. | Learner orders picture cards for morning, school, home, and evening routine. |

## Local Resource Bank

- Counting and number: cups, tins, plates, spoons, jugs, mugs, sticks, bottle tops, seeds, number cut-outs, number charts.
- Number writing: sand trays, plasticine, chalk, crayons, paper, flash cards, tracing sheets, phone/tablet for supervised typing.
- Length: boxes, chairs, tables, rulers, strings, sticks, picture cards.
- Mass: spoons, cups, plates, paper, books, tins, pans, sufurias, safe classroom objects.
- Capacity: cups, tins, bottles, jugs, basins, water, sand, soil.
- Time: calendars, picture cards, daily routine charts, home/school routine photos.

## Digital Support Rules

- Use digital tracing only after learners have formed numerals with concrete materials.
- Use matching and sequencing games for practice, not as the first teaching experience.
- Use teacher photo/audio notes as evidence, not as learner screen time.
- Keep every digital task paired with a physical classroom task.
