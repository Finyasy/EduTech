# PP1 Mathematical Activities Assessment Bank

## Mastery Levels

| Level | Descriptor | Teacher evidence |
| --- | --- | --- |
| Exceeds expectation | Completes the task independently and explains the choice or process. | Learner performs accurately, uses correct vocabulary, and can show another learner what to do. |
| Meets expectation | Completes the task correctly with normal instruction. | Learner performs the task after whole-class or small-group instruction. |
| Approaches expectation | Completes part of the task with support. | Learner needs prompting, modeling, or repeated demonstration. |
| Below expectation | Cannot complete the task without direct guidance. | Learner is not yet able to perform the target action even after support. |

## Rubric Bank By Sub-Strand

| Sub-strand | Exceeds expectation | Meets expectation | Approaches expectation | Below expectation |
| --- | --- | --- | --- | --- |
| Sorting and grouping | Sorts objects by more than one attribute and explains the rule. | Sorts objects by one given attribute. | Sorts some objects correctly with prompts. | Cannot sort by the given attribute yet. |
| Matching and pairing | Matches or pairs objects and explains likeness, use, or sameness. | Matches or pairs objects by one clear attribute. | Matches some objects with teacher support. | Cannot match similar objects yet. |
| Counting concrete objects | Counts a set accurately and checks the count independently. | Counts the target set correctly with normal instruction. | Counts part of the set or skips/double-counts with support. | Cannot count the target set yet. |
| Number recognition | Identifies target numerals and matches them to quantities. | Identifies target numerals. | Identifies some numerals with prompts. | Cannot identify target numerals yet. |
| Number sequencing | Orders numbers and names what comes before or after. | Orders the target number range correctly. | Orders part of the sequence with support. | Cannot order the target numbers yet. |
| Missing numbers | Completes missing-number tasks and explains the missing value. | Places the missing number correctly. | Chooses from options with support. | Cannot identify the missing number yet. |
| Number writing | Forms recognizable numerals and links them to quantities. | Traces, models, joins, or writes the target numeral recognizably. | Forms part of the numeral with support. | Cannot form the target numeral yet. |
| Digital number writing | Types or traces a number digitally and matches it to a physical card or quantity. | Types or traces the target number digitally. | Selects the number with prompts. | Cannot use the digital task for the target number yet. |
| Long/short | Compares objects, identifies long/short, and explains the comparison. | Identifies long or short examples correctly. | Identifies some examples with support. | Cannot identify long/short yet. |
| Heavy/light | Sorts and compares objects using heavy/light safely and correctly. | Identifies heavy and light objects correctly. | Identifies some objects with prompts. | Cannot identify heavy/light yet. |
| Capacity | Compares containers using full/empty, big/small, more/less, or holds more. | Uses containers to fill, empty, sort, or compare correctly. | Performs part of the comparison with support. | Cannot compare containers yet. |
| Daily routine/time | Sequences routine cards and uses time words correctly. | Orders familiar routine events correctly. | Orders some routine events with prompts. | Cannot sequence routine events yet. |

## Learner Evidence Checklist

Use this as a per-learner checklist for PP1 Term 2 review.

| Evidence item | Term 2 target | Collection method |
| --- | --- | --- |
| Counting evidence | Counts object sets 5-9 | Teacher observation or photo of object set |
| Number sequence evidence | Orders numbers within 1-9 | Number cut-out task |
| Missing-number evidence | Completes a simple missing-number strip | Worksheet or teacher note |
| Number writing evidence | Models, traces, joins, writes, or types numbers | Portfolio sample |
| Long/short evidence | Identifies long and short sides or objects | Sorting/matching task |
| Heavy/light evidence | Sorts safe objects into heavy and light groups | Observation checklist |
| Capacity evidence | Fills, empties, and compares containers | Performance task |
| Daily routine evidence | Orders routine cards for morning/school/home/evening | Picture-card task |
| Oral language evidence | Uses target vocabulary in context | Teacher note or audio note |
| Collaboration evidence | Takes turns, works in pairs, and explains choices | Observation checklist |

## Teacher Observation Prompts

- What did the learner do independently?
- What vocabulary did the learner use correctly?
- Did the learner count each object once?
- Did the learner explain why objects were grouped, matched, or compared?
- Did the learner need modeling, verbal prompts, or hand-over-hand support?
- What is the next small task that would move this learner forward?

## Review Guidance

- Do not rely on oral questions alone when a performance task is possible.
- Keep evidence short and practical; one good artifact per sub-strand is enough for review.
- Record the support level, not just whether the answer was correct.
- Treat home activities as enrichment evidence, not as the only proof of mastery.
